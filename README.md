# Blindagem Total: Cabine Limpa

Jogo educativo de biossegurança para turmas de pós-graduação em Estética.
O estudante atua como auditor de uma cabine durante uma **limpeza de pele com
extração de comedões**: inspeciona três cenas, associa os riscos às camadas de
proteção e decide dilemas profissionais.

**Jogar:** https://pollxtroy-create.github.io/blindagem-total-web/

## Como funciona

Arquivo único `index.html` (617 KB), com HTML, CSS, JavaScript e as três
fotografias embutidas em Base64. Sem dependência externa, sem requisição de
rede depois do carregamento e **sem qualquer persistência** — nenhum dado do
estudante é gravado ou enviado, e recarregar a página reinicia a sessão.

Funciona no celular a partir de 360 px e no computador, onde a partir de 920 px
o layout vira duas colunas.

## Sobre as imagens

As três cenas são **simulações encenadas, geradas para fins educacionais**.
Pessoas e ambiente são fictícios. A identificação aparece sob cada foto dentro
do jogo.

## Base normativa

Os itens distinguem **exigência normativa**, **recomendação técnica** e **regra
institucional**, com a fonte citada em cada um (NR-32, NR-6, RDC 222/2018 e
orientações da Anvisa). A verificação das fontes primárias, os prompts de
geração das imagens e o guia de manutenção ficam no projeto de origem, fora
deste repositório de publicação.

## Limite de escopo

O resultado apresentado ao final mede o desempenho **nesta simulação**. Não é
avaliação de segurança de uma clínica real nem certificação profissional.
